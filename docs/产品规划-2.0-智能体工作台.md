## 2. 一句话定位

**袖里乾坤**是本机智能体工作台：左侧管 Agent 与会话，中间对话协作，知识库沉淀分析与资讯；**今日运势**与**股票参谋**既是 Agent，也保留经典整页；无登录、可扩展自定义智能体。

## 3. 产品结构总览

```
袖里乾坤
├── 工作台（对话壳 · 默认首页）
│   ├── 内置 Agent：今日运势 / 股票参谋
│   ├── 自定义 Agent（2.0 后期开放创建）
│   └── 会话 · 工具调用 · 卡片消息
├── 经典页（长期并存）
│   ├── /fortune  运势整页
│   ├── /stocks   股票整页
│   └── /calendar 日历（挂件入口）
├── 知识库
│   ├── 自动入库（报告 / 资讯 / 运势快照）
│   ├── 手动收藏
│   └── 检索增强分析
├── 桌面挂件（独立窗）
└── 设置（侧栏分区 · 无登录）
```

对标关系（体验，非抄袭）：

| 参照 | 袖里乾坤吸收什么 |
|------|----------------|
| **豆包** | 圆润对话壳、空态欢迎、底部输入条、模型选择 |
| **Codex** | 工作区感、任务过程态、工具/产物可回看 |
| **WorkerBuddy / 星源类** | Agent 分组会话、设置侧栏、能力可扩展 |

## 4. 信息架构与双开路由

### 4.1 主导航（建议）

左侧不再只有「工具平铺」，改为：

1. **工作台**（对话）
2. **知识库**
3. **运势**（经典 `/fortune`）
4. **股票**（经典 `/stocks`）
5. **日历**（`/calendar` / 打开挂件）
6. 底部：**设置** · **关于**

或：左侧主栏仅「工作台 / 知识库 / 应用」，「运势·股票·日历」放在「应用」分组——两种都可，**经典页入口必须永久可见**。

### 4.2 路由并存策略（已拍板）

| 路由 | 角色 | 长期策略 |
|------|------|----------|
| `/` 或 `/workbench` | 智能体工作台 | 默认启动页（可设） |
| `/fortune` | 经典运势整页 | **永久保留**，与 Agent 数据互通 |
| `/stocks` | 经典股票整页 | **永久保留**，与 Agent / 知识库互通 |
| `/knowledge` | 知识库 | 2.0 新增 |
| `/calendar` | 日历 | 保留 |
| `/settings` | 设置工作台 | 侧栏分区重做 |
| `/agents/:id/sessions/:sid` | 深链到某会话 | 可选 |

**同步规则**

- 经典页「生成今日报告 / 今日运势」→ 同时可写入对应 Agent 会话一条卡片消息（可关）
- Agent 对话生成的报告 ↔ 经典页历史报告同一数据源
- 知识库收藏两边都能「加入知识库」

## 5. 内置智能体

### 5.1 共同模型

| 字段 | 说明 |
|------|------|
| `id` / `name` / `icon` / `description` | 展示 |
| `systemPrompt` + `tools[]` | 本地编排 |
| `defaultModel` | 可覆盖全局默认 |
| `knowledgeScopes[]` | 默认可检索的知识库分区 |
| `sessions[]` | 本地会话 |
| `entryPoints` | `workbench` / `classic:/fortune` 等 |

消息类型：`text` · `card.*` · `system` · `tool` · `knowledge.cite`（标注引用了哪些知识条目）。

### 5.2 今日运势 Agent

- 生辰 / 流派 / 起卦 / 可选 AI 润色（复用现有模块）
- 可把每日快照入库；追问时可检索「近 7 日运势」
- 工具：打开挂件、复制摘要、写入知识库

### 5.3 股票参谋 Agent

- 自选 / 扫描 / 多源资讯 / 区间涨跌 / 公司简介（复用现有）
- **分析前可选**：是否注入知识库中的历史报告、已收藏资讯、用户笔记
- 工具：生成报告、打开走势、入库、对比历史结论

### 5.4 自定义智能体（扩展，2.0 后半段开放）

用户可创建：

- 名称、头像色、人设 Prompt
- 勾选工具包（运势工具 / 股票工具 / 知识库检索 / 网页无 → 仅本地工具）
- 绑定知识库分区
- 默认模型

**不做**：云端模板市场、账号同步。导出/导入 Agent 配置包（JSON）可做本机备份。

## 6. 知识库（完整 RAG · 含用户上传）

> 详见 [`docs/知识库技术方案.md`](./知识库技术方案.md)（v0.2）。

### 6.1 切片存 SQLite 合适吗？

**合适，且是业界 local-first RAG 主流。**  
KnowNote / RAGdoll / Psyche / vstash 等均为：**SQLite 存文档与切片正文 + FTS5 + 同库向量（sqlite-vec）**；原文件放磁盘。  
独立 Qdrant/Milvus、Postgres+pgvector 面向服务端规模；个人桌面不必。向量极大时可将 **向量引擎** 换 LanceDB，**切片正文仍作 SQLite 权威数据**。

### 6.2 完整能力（一次设计到位）

- 多 Collection；用户上传（md/txt/pdf/docx/html/csv）+ 系统产物入库  
- 结构感知切分 + 增量 hash 重索引  
- **混合检索**：分词 FTS5/BM25 + Embedding 向量 + **RRF** + **MMR**；可选本地 Rerank  
- Embedding **双通道**：API 与本地 ONNX/Ollama  
- 引用强制可见；任务队列、容量、备份、整库重建  

### 6.3 组件定案

| 层 | 选型 |
|----|------|
| 原件 | `knowledge/blobs/` |
| 切片 + 元数据 | **SQLite**（建议独立 `knowledge.db`） |
| 词法 | **FTS5 BM25** + 中文分词 |
| 向量 | **sqlite-vec**（与切片同库） |
| 融合 | RRF + MMR（自研公式实现） |

### 6.4 算法：要，但是标准 RAG 栈

切分用规则（标题/段落/滑窗），不靠语义切边界模型。  
检索侧必须具备：分词、BM25、Embedding、KNN、RRF、MMR；（可选）Cross-Encoder。  
**不是「先关键字以后再说向量」——混合检索是完整功能的一部分。**

## 8. 视觉与设计系统重做（必须有设计感）

### 8.1 现状问题（1.x）

偏工具后台：灰边框多、直角感、色彩克制到「没记忆点」、卡片信息密。2.0 要对齐消费级 AI 工作台，而不是企业后台。

### 8.2 设计原则

| 原则 | 落地 |
|------|------|
| **圆润** | 大圆角半径体系：`16 / 20 / 28`；按钮 pill；头像与 Agent 图标全圆或超圆角 |
| **色彩鲜明** | 潮青主色提高饱和；珊瑚/晴空蓝作次强调；浅色大面积留白 + 柔和色块分区，不是一片灰 |
| **有层次** | 侧栏微渐变或淡色底；主区纯净；卡片轻阴影（单层，忌多层光晕堆砌） |
| **呼吸感** | 更大间距；列表不要贴边；空态要「舞台感」 |
| **动效克制有存在感** | 会话切换、气泡入场、chip 轻弹 2～3 处有意动效即可 |
| **双主题** | Light 为主视觉（鲜明）；Dark 降低饱和但仍潮青点缀，不做纯黑赛博紫 |

### 8.3 Token 草案（替换「霜灰·潮青」过灰部分）

```
--color-brand:        #0FBEA8;
--color-brand-strong: #0B9F8C;
--color-accent:       #FF7A59;   /* 珊瑚：CTA / 收藏 */
--color-accent-2:     #4C8DFF;   /* 晴空：知识库 / 链接 */
--color-bg:           #F4FBFA;
--color-bg-elevated:  #FFFFFF;
--color-sidebar:      #E7F7F4;
--radius-lg:          20px;
--radius-xl:          28px;
--shadow-card:        0 8px 28px rgba(15, 100, 90, 0.08);
```

**禁止默认成**：紫白渐变 AI 脸、奶油衬线报刊风、过度 glow。

### 8.4 关键组件要重画

- 侧栏 Agent 行（圆图标色盘 + 活跃 pill）
- 对话气泡与**结果大卡片**（报告/运势）
- 底部输入「胶囊船」：内嵌工具条 + 圆形发送
- 知识库卡片与 cite 胶囊
- 设置侧栏 + 分区标题
- 经典 `/fortune`、`/stocks` **同步换皮**（同一 token，避免工作台很新、经典页很旧）

### 8.5 设计交付物（建议顺序）

1. Token + 字体（展示用圆润无衬线，正文可读性优先）  
2. 工作台空态 / 有消息 各一屏  
3. 知识库列表 + 详情  
4. 设置侧栏  
5. 经典运势 / 股票页换皮  
6. 图标正式稿（icns / png / tray）
