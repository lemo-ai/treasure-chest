# 调度与通知

> 对齐 **0.4.0** · 2026-09-18

---

## 1. 定时任务（Schedules）

页面：`/schedules`。卡片式管理：创建、编辑、启用/禁用、立即执行、删除。

### 1.1 动作类型

| 类型 | 说明 |
|------|------|
| `fortune_notify` | 推送今日运势（内置任务常见） |
| `stocks_report` | 自动生成荐股报告并通知 |
| `agent_turn` | 向指定智能体发送固定提示词（可挂 Skill / MCP / 知识库 / 数据源 / 联网等） |

内置示例（安装后可改可关）：

- 运势每日提醒  
- 荐股报告  
- 体彩参谋：爬取入库 + 每日简报（`agent_turn`）  

内置「领域动作」与「智能体回合」在编辑器上的可改字段不同：后者可改提示词与能力集；运势/荐股类动作更固定，主要改时间与投递。

### 1.2 触发方式

| 模式 | 含义 |
|------|------|
| `once` | 单次 |
| `daily` | 每天固定时刻 |
| `interval` | 固定间隔 |
| `window` | 时间窗内多次 |

### 1.3 报告与展示

- 报告格式：Markdown / HTML（工作台通知按格式渲染）  
- 钉钉等通道若只支持 Markdown，HTML 会转为可读文本再推送  

### 1.4 与工作台队列的关系

定时任务在主进程调度执行，**独立于**工作台会话发送队列。会话队列只解决「人工对话时边回边排」。

---

## 2. 通知（Notifications）

页面：`/notifications`。

| 能力 | 说明 |
|------|------|
| 收件箱 | 查看定时任务与系统提醒的完整结果 |
| 未读 | 侧栏角标 |
| 桌面通知 | 系统 Notification（可按任务开关） |

---

## 3. 投递通道（设置）

全局配置，任务可覆盖：

| 通道 | 说明 |
|------|------|
| 工作台通知中心 | 默认收件箱 |
| 系统桌面通知 | OS 级横幅 |
| 钉钉机器人 | Webhook；可选加签 |
| SMTP 邮件 | 用户配置发件服务器 |

通道密钥与邮箱密码同样按安全存储策略处理，勿写入公开配置或文档示例。

---

## 4. 代码入口

| 路径 | 内容 |
|------|------|
| `electron/modules/schedules/` | 调度持久化与执行 |
| `electron/modules/notifications/` | 收件箱与投递 |
| `src/features/schedules/` | 定时任务 UI |
| `src/features/notifications/` | 通知 UI |
| `packages/shared/` | 任务类型、状态枚举与 IPC |
