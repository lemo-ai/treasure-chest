# 智能体与能力

> 对齐 **0.6.0** · 2026-09-21

---

## 1. 智能体模型

每个 Agent 具备：人设 / 系统提示、可用工具集、可选 Skill、MCP、知识库分区、数据源、默认模型、快捷问题、Logo 等。

| 来源 | 说明 |
|------|------|
| **内置** | 应用预置，部分人设可编辑（如体彩） |
| **自定义** | 设置或侧栏「添加智能体」创建；本地持久化；可删除 |

入口：侧栏「智能体」分组 → `/?agent=<id>` 打开工作台对应会话。

---

## 2. 内置智能体

| ID | 名称 | 要点 |
|----|------|------|
| `direct` | 直连模型 | 无领域人设；通用工具 + 编码沙箱 |
| `fortune` | 今日运势 | 日运 / 卦象；工具如 `get_daily_fortune`、`get_weather` |
| `stocks` | 股票参谋 | 检索行情与报告；`search_web`、`search_stock`、`get_stock_quote`、`get_latest_stocks_report`、`fetch_url`、`crawl_url` 等 |
| `lottery` | 体彩参谋 | 预装人设；默认数据源 `builtin:lottery-sqlite`；侧重分析流水线；编码/插件/子智能体等能力按产品策略收紧 |

运势生辰、股票市场开关与扫描池等在**设置**中配置，由领域服务供 Agent / 定时任务调用。

---

## 3. 工作台能力开关（会话级）

典型可组合能力（以 UI / Agent 配置为准）：

- 模型 Provider / 具体模型  
- `@知识库` 引用与 `search_knowledge`  
- 联网检索与网页抓取 / 爬取  
- MCP 工具（`mcp__*` 动态挂载）  
- Skill 注入  
- 编码沙箱（Harness）：读改文件、shell、git、子 Agent 等  
- **发送队列**：流式回复进行中可排队后续用户消息  
- **语音输入**：麦克风 → Web Speech 听写（本机 / 系统 STT，无强制云账号）  
- **面板**：轨迹（含子智能体编排看板）、终端、Memory、产物  

---

## 4. 工作区 Project

侧栏「工作区」与工作台顶栏同步：

- 绑定 **工作目录**（编码沙箱根）、可选知识分区、默认 Agent / Skill / MCP / 数据源  
- 可选 **Rules 路径**（如 `AGENTS.md`）+ 设置中的全局编码规则，注入启用编码工具的对话  
- 会话可归属 Project；写文件走 **diff 审阅**（接受 / 拒绝），与工具审批一致  

---

## 5. Memory 与产物

| 能力 | 说明 | 边界 |
|------|------|------|
| **Memory** | 短事实：全局 / `agent:` / `project:` 作用域；可开关「注入后续对话」 | **不是**知识库；不做大文档 RAG |
| **产物** | 会话级 Artifacts（代码、Markdown、媒体等）预览 / 复制 / 另存 | 本机持久化；与知识库分区无关 |

---

## 6. 内置 LLM 工具（摘要）

实现见 `electron/modules/llm/tools/`（如 `builtinTools.ts`）。按 Agent 白名单挂载，不是全局一锅端。

| 类别 | 示例 |
|------|------|
| 信息 | 天气、网页搜索、抓取 URL、站点爬取 |
| 知识 | 知识库检索 |
| 数据 | `list_data_sources`、`query_data_source` |
| 领域 | 运势、股票报价 / 报告 |
| 媒体 | 图片 / 视频 / 音乐生成（依赖已配置的多模态 Provider） |
| 编码 | Harness：`read_file`、`write_file`、`run_shell`、`git_*`、`spawn_subagent` 等 |
| Computer Use | `browser_*`、`os_open_url`、`os_open_path`（见 §11，默认关闭） |

联网搜索策略偏向中文场景可用性（国内源优先与超时回退等，以代码为准）。

## 7. Skills

- 存储与管理：`electron/modules/skills`  
- 内置示例：会议纪要、邮件润色、SWOT、代码解释、数据流水线（crawl → SQL → 分析）、体彩数据源用法  
- 可从外部目录安装 `SKILL.md`（设置中配置目录源，如公开 Skills 仓库）  
- 工作台与定时「智能体回合」可勾选 Skill IDs  

---

## 8. MCP

- 传输：stdio、SSE  
- 设置页卡片管理；首次空列表可 seed 官方示例：Memory（MCP 服务名）、Sequential Thinking、Filesystem（限工作区）、Everything(demo)  
- 按 server 启用；工具名以 `mcp__` 前缀进入模型工具列表  
- Agent 与定时任务均可绑定 MCP 集合  
- 注意：官方 seed「Memory」MCP ≠ 产品内建 Memory 面板  

---

## 9. 数据源

- 设置「数据源」：卡片增删改、按需安装驱动、连接测试  
- 支持种类较多：HTTP、本地文件、SQLite/DuckDB、主流 SQL/NoSQL、时序与向量库等（完整列表以 `dataSources` 模块为准）  
- 预置 **`builtin:lottery-sqlite`**：安装包可带 `lottery.db`；本机已有爬取数据时可迁移  
- Agent 通过列表/查询工具读数；创建/编辑 Agent 时可绑定数据源  

---

## 10. 编码沙箱（Harness）

- 面向「直连模型」等工作区编程场景  
- 无头模式：`npm run harness` / `harness:dev`（`--harness-headless`）  
- 权限与工作目录由主进程约束，避免任意扩散到整盘  
- 写文件 / shell 等走审批；diff 可预览后接受  
- **子智能体**：聊天内 `SubagentCard`；轨迹面板「子智能体编排」看板（运行中 / 完成 / 失败）  

---

## 11. Computer Use（本机 / 浏览器轻操控）

设置 → **本机操控**；**默认关闭**。

| 允许 | 说明 |
|------|------|
| `browser_navigate` / `click` / `type` / `read_text` / `screenshot` | 应用内隐藏 BrowserWindow（非 Playwright） |
| `os_open_url` | 用系统默认浏览器打开 http(s) |
| `os_open_path` | 打开已存在的本地路径（沙箱相对路径或绝对路径） |

| 约束 | 说明 |
|------|------|
| 强审批 | 所有 Computer Use 工具均为 confirm；支持本会话始终允许 |
| 域名白名单 | 可限制可导航主机；空 = 不限制主机但仍需审批 |
| 禁止 | 任意键鼠、未审批的系统级控制、支付类工具名 |

---

## 12. 用量

设置 → **用量与规则**：本机统计 token / 调用次数，可选单价估算与 CSV 导出；全局编码规则与 Project Rules 一并注入。

---

## 13. 自定义 Agent 建议流程

1. 设置 → 智能体 → 新建（或侧栏添加）  
2. 写清人设与快捷问题  
3. 按需绑定：模型、知识库分区、数据源、MCP、Skill  
4. 可选：创建工作区 Project 钉死目录与规则  
5. 在工作台试跑；需要日报则加一条「智能体回合」定时任务
