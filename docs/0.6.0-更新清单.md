# 0.6.0 更新清单

> 目标版本：**0.6.0**  
> 主题：**工作区与产出**（钉住上下文、留住结果、本机能持续干活）  
> 状态图例：`[ ]` 待做 · `[~]` 进行中 · `[x]` 已完成  
> 原则：本机优先；少堆工具箱页面；不做云账号 / 多租户；**本版本一次收齐，不再拆 0.6.1 / 0.7**。

对照市面：Claude / ChatGPT / 豆包桌面（Projects · Memory · Artifacts）、Cursor / Codex（Rules · diff 审阅）、Manus / OpenClaw 类（浏览器 · 长任务续聊）。  
0.5.0 已补「看得见过程、敢交给它」。**0.6.0 补「交给它之后能稳定产出」**——工作区、记忆、产物、编码审阅、定时续聊、用量、本机/浏览器操控、签名自动更新、语音输入。

发版操作见 [发版流程](发版流程.md)。功能落地并通过本地测试后，再 bump `package.json` / `config/changelog.json` 并打 `v0.6.0`。

## P0 — 主题立住（必须进 0.6.0）

### 1. 工作区 Project `[x]`
对标：Claude Projects / Cursor Workspace。

- [x] 数据模型：名称、工作目录、绑定知识分区、默认 Agent / Skill / MCP / 数据源、可选项目规则路径（SQLite `projects` + migration 11）
- [x] 侧栏可创建 / 切换 / 归档 Project；会话 `project_id` 归属
- [x] 进入 Project 后：工作目录写入沙箱、知识分区带入对话、会话列表按工作区过滤
- [x] 与现有「智能体侧栏」共存：无 Project（「全部会话」）时行为与 0.5 一致
- [x] zh-CN / en-US

### 2. 跨会话 Memory（本机） `[x]`
对标：ChatGPT Memory / Claude 记忆。与知识库区分：**知识库 = 资料；Memory = 关于用户 / 项目的短事实与偏好**。

- [x] 全局 / 智能体 / Project 级 Memory；SQLite `memory_facts`；旧 localStorage 自动迁移
- [x] 注入策略：回合自动带入（上限）；面板可关闭注入
- [x] 面板：列表查看 / 编辑 / 遗忘；作用域选择
- [ ] Agent 可提议写入并需确认（留给后续打磨）
- [x] 与知识库检索并存，不互相替代
- [x] zh-CN / en-US

### 3. Artifacts / 产物一等公民 `[x]`
对标：Claude Artifacts / Canvas。复用并做实工作台「产物」面板。

- [x] 回合产出落入产物列表（SQLite）；可预览 / 复制 / 另存 / 删除
- [x] 通知：保存为产物 + 基于此续聊（并可选写入产物）
- [x] 会话导出 Markdown 默认附带产物附录
- [x] 轨迹 / 面板入口与产物状态一致；空态与 i18n
- [ ] 产物「再编辑」深度编辑器（本版预览足够，后续可加）

## P1 — 强烈建议同版本带上

### 4. 编码审阅闭环（Rules + diff） `[x]`
对标：Cursor apply / review。

- [x] 全局规则（设置「用量与规则」）+ 工作区 `rulesPath` / 沙箱 `AGENTS.md` 注入 system prompt
- [x] `write_file` / `str_replace_file` / `apply_patch`：审批弹窗展示 before/after 行级 diff → 接受 / 拒绝 / 本会话始终允许
- [x] 拒绝不落盘（审批在 execute 之前）；本会话始终允许跳过后续确认（与既有审批策略一致）
- [x] zh-CN / en-US

### 5. 定时结果可续聊 `[x]`
延续 0.5 ephemeral 调度：结果进通知，不建垃圾会话；需要时再「接着干」。

- [x] 通知 / 收件箱：一键「基于此续聊」（带任务摘要上下文）
- [x] 挂到当前 Project（若已激活）；不预建空会话
- [x] 与 Artifacts 打通（长文自动或手动保存为产物）
- [x] zh-CN / en-US

### 6. 用量与费用可见 `[x]`

- [x] 按会话 / 按天统计 token（prompt / completion）；可配置 $/1M 单价估算费用
- [x] 设置 →「用量与规则」查看；可导出 CSV、清空
- [x] 仅本地 `app_settings` 持久化
- [x] zh-CN / en-US
- [x] 接口无 usage 时按字符估算并标注

## P2 — 执行面与分发（仍进 0.6.0，可 gated）

### 7. 浏览器 / 本机轻操控 `[x]`
对标：Manus / Computer Use 类；**默认关闭，强审批**。

- [x] 受限浏览器自动化（Electron 隐藏 BrowserWindow，非 Playwright）：打开 URL、点击、填表、截图；域名白名单
- [x] 可选轻量本机操控（`os_open_url` / `os_open_path`）——范围写清，禁止未审批的任意系统控制
- [x] 工具步骤卡 + 审批流完整可见；支持本会话始终允许（与 0.5 审批一致）
- [x] 安全说明写入设置（Settings → Computer use）与清单；失败可重试
- [x] zh-CN / en-US

### 8. 正式签名 + 自动更新可用 `[x]`
在 0.5「检查更新 / 可选 CI 签名」基础上做到日常可用。

- [x] macOS：`CSC_*` + 公证凭据齐全时 Release 产出已签名 / 已公证包（空 secret 跳过）
- [x] Windows：有 `WIN_CSC_*` / `CSC_*` 时签名；无证书时日志与文案清晰
- [x] 应用内更新：签名包可走自动更新；未签名继续引导手动下载（与 0.5 一致）
- [x] [发版流程](发版流程.md) 补齐 mac/Win 密钥清单与排障

### 9. 语音输入 `[x]`

- [x] 工作台输入区：点击麦克风语音转写（Web Speech / 本机 STT，无强制云账号）
- [x] 权限与隐私说明（entitlements + `NSMicrophoneUsageDescription`）；失败态与 i18n
- [x] 不强制依赖云账号
