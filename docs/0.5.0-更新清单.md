# 0.5.0 更新清单

> 目标版本：**0.5.0**  
> 主题：**信任感与闭环体验**（看得见过程、敢交给它、装得上更新得了）  
> 状态图例：`[ ]` 待做 · `[~]` 进行中 · `[x]` 已完成  
> 原则：本机优先；少堆工具箱页面；先补「用得稳」再扩「花样多」。

对照市面工作台（豆包桌面 / Claude·ChatGPT 桌面 / Cursor·Codex 类），0.4.x 已具备对话壳、知识库、调度、数据源、领域 Agent。**0.5.0 不追求功能清单变长，而补齐信任与分发短板。**

发版操作见 [发版流程](发版流程.md)。本清单功能落地并通过你本地测试后，再 bump `package.json` / `config/changelog.json` 并打 `v0.5.0`。
