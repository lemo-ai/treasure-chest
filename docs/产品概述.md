## 1. 品牌与定位

| 项 | 内容 |
|----|------|
| 中文名 | **袖里乾坤** |
| 英文短名 | **Qiankun** |
| 副标题 | 本机智能体工作台 |
| 工程名 | `treasure-chest`（npm / git 可暂留） |
| App ID | `com.lemo.treasure-chest` |
| 曾用名 | 百宝箱 |

**一句话**：左侧管智能体、工作区与会话，中间对话协作并留下 Memory / 产物，知识库沉淀资料，定时任务自动跑日报，工具箱覆盖日常与音视频文档——全程本机、无需账户登录。

侧栏副标题文案：**智能体指挥中枢**（英文：Agent Command Hub）。

---

## 2. 产品原则

1. **本机优先**：配置、会话、知识库、工作区、记忆与产物默认落在应用 `userData`，不上自建云账号体系  
2. **无强制登录**：仅向用户配置的 AI / 向量 / 数据库等 endpoint 发请求  
3. **密钥隔离**：API Key 使用操作系统安全存储  
4. **可扩展**：自定义智能体、Skill、MCP、数据源、定时任务  
5. **中英界面**：`zh-CN` / `en-US`，设置内即时切换  
6. **可审批执行**：写文件、本机/浏览器操控等副作用工具默认强审批

## 3. 信息架构（当前路由）

应用使用 Hash 路由（`src/app/router.tsx`）。

```
袖里乾坤
├── 工作台          /  · /workbench          默认首页 · 多智能体对话
│   ├── 面板：轨迹 / 终端 / 记忆 / 产物
│   └── 顶栏：工作区 Project 切换（与侧栏同步）
├── 知识库          /knowledge
├── 工作区（侧栏）  Project                 绑定目录 · 知识分区 · 规则
├── 智能体（侧栏）  /?agent=<id>             内置 + 自定义，非独立整页
├── 定时任务        /schedules
├── 万年历          /calendar
│   └── 桌面挂件    /calendar/widget         独立窗
├── 工具箱          /tools
│   ├── 时间戳 / 时区 / 世界时间 / JSON
│   ├── 网页爬虫
│   └── 图片 / 视频 / 音频 / 文档
├── 设置            /settings
│   ├── 用量与规则 · 本机操控（Computer Use）
│   └── 模型 / 本地 LLM / MCP / 数据源 …
├── 通知            /notifications
└── 版本变更        /changelog
```

**已收敛**：运势、股票**不再**提供独立经典整页（早期规划中的 `/fortune`、`/stocks` 双开已取消），统一为工作台智能体 + 设置中的运势/股票配置 + 定时任务。

## 4. 模块说明摘要

| 模块 | 用户价值 |
|------|----------|
| **工作台** | 多智能体对话；工具步骤可见；发送队列；知识库 / 联网 / MCP / Skill / 编码沙箱；轨迹侧栏含子任务看板；语音输入 |
| **工作区 Project** | 绑定工作目录、知识分区、默认 Agent/Skill/MCP、可选 Rules；会话可归属项目 |
| **Memory** | 跨会话短事实（全局 / Agent / 项目作用域）；可注入后续对话；**不是**知识库 RAG |
| **产物 Artifacts** | 会话产出物（代码块、长文、媒体等）集中预览、复制、另存 |
| **智能体** | 直连模型、今日运势、股票参谋、体彩参谋；可创建自定义 Agent |
| **知识库** | 本机 RAG：分区树、多格式入库、FTS + 向量 / 混合检索、对话引用 |
| **定时任务** | 运势通知、荐股报告、智能体回合；结果进通知并可续聊 |
| **通知** | 收件箱查看完整结果；未读角标；可带回工作台续聊 |
| **万年历** | 公历农历、班休标注；可选桌面挂件 |
| **工具箱** | 效率小工具 + 爬虫 + 音视频图片文档处理 |
| **设置** | 模型、本地 LLM、MCP、数据源、技能、通知、**用量与规则**、**本机操控**、主题与备份等 |

细节见同目录 [智能体与能力](智能体与能力.md)、[知识库](知识库.md)、[调度与通知](调度与通知.md)。

## 6. 免责与隐私

| 场景 | 说明 |
|------|------|
| 通用 AI | 回复仅供参考，不构成投资、医疗或法律建议 |
| 运势 | 传统文化娱乐与自我反思，不构成现实决策指导 |
| 股票 | 学习参考，不构成投资建议；市场有风险 |
| 体彩 / 爬虫 | 研究分析用，不构成购彩建议；遵守 robots/ToS，勿高频抓取 |
| Computer Use | 默认关闭；开启后仍需审批；勿对未信任站点启用 |
| 隐私 | 无本项目运营的业务数据上传后端；流量只到用户配置的 endpoint；本地可导出备份；语音听写走系统 Web Speech（可不依赖云账号） |
