## 1. 品牌与定位

| 项 | 内容 |
|----|------|
| 中文名 | **袖里乾坤** |
| 英文短名 | **Qiankun** |
| 副标题 | 本机智能体工作台 |
| 工程名 | `treasure-chest`（npm / git 可暂留） |
| App ID | `com.lemo.treasure-chest` |
| 曾用名 | 百宝箱 |

**一句话**：左侧管智能体与会话，中间对话协作，知识库沉淀资料，定时任务自动跑日报，工具箱覆盖日常与音视频文档——全程本机、无需账户登录。

侧栏副标题文案：**智能体指挥中枢**（英文：Agent Command Hub）。

---

## 2. 产品原则

1. **本机优先**：配置、会话、知识库、爬取数据默认落在应用 `userData`，不上自建云账号体系  
2. **无强制登录**：仅向用户配置的 AI / 向量 / 数据库等 endpoint 发请求  
3. **密钥隔离**：API Key 使用操作系统安全存储  
4. **可扩展**：自定义智能体、Skill、MCP、数据源、定时任务  
5. **中英界面**：`zh-CN` / `en-US`，设置内即时切换

## 3. 信息架构（当前路由）

应用使用 Hash 路由（`src/app/router.tsx`）。

```
袖里乾坤
├── 工作台          /  · /workbench          默认首页 · 多智能体对话
├── 知识库          /knowledge
├── 智能体（侧栏）  /?agent=<id>             内置 + 自定义，非独立整页
├── 定时任务        /schedules
├── 万年历          /calendar
│   └── 桌面挂件    /calendar/widget         独立窗
├── 工具箱          /tools
│   ├── 时间戳 / 时区 / 世界时间 / JSON
│   ├── 网页爬虫
│   └── 图片 / 视频 / 音频 / 文档
├── 设置            /settings
├── 通知            /notifications
└── 版本变更        /changelog
```

**已收敛**：运势、股票**不再**提供独立经典整页（早期规划中的 `/fortune`、`/stocks` 双开已取消），统一为工作台智能体 + 设置中的运势/股票配置 + 定时任务。

## 4. 模块说明摘要

| 模块 | 用户价值 |
|------|----------|
| **工作台** | 多智能体对话；工具调用可见；发送队列；可挂知识库 / 联网 / MCP / Skill / 编码沙箱 |
| **智能体** | 直连模型、今日运势、股票参谋、体彩参谋；可创建自定义 Agent |
| **知识库** | 本机 RAG：分区树、多格式入库、FTS + 向量 / 混合检索、对话引用 |
| **定时任务** | 运势通知、荐股报告、智能体回合；单次/每天/间隔/时间窗；多通道投递 |
| **通知** | 收件箱查看完整结果；未读角标 |
| **万年历** | 公历农历、班休标注；可选桌面挂件 |
| **工具箱** | 效率小工具 + 爬虫 + 音视频图片文档处理 |
| **设置** | 模型、本地 LLM、MCP、数据源、技能、通知通道、主题与备份等 |

细节见同目录 [智能体与能力](智能体与能力.md)、[知识库](知识库.md)、[调度与通知](调度与通知.md)。

## 6. 免责与隐私

| 场景 | 说明 |
|------|------|
| 通用 AI | 回复仅供参考，不构成投资、医疗或法律建议 |
| 运势 | 传统文化娱乐与自我反思，不构成现实决策指导 |
| 股票 | 学习参考，不构成投资建议；市场有风险 |
| 体彩 / 爬虫 | 研究分析用，不构成购彩建议；遵守 robots/ToS，勿高频抓取 |
| 隐私 | 无本项目运营的业务数据上传后端；流量只到用户配置的 endpoint；本地可导出备份 |
